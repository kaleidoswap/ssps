# Security

Report a vulnerability in the specification, or in a deployment that follows
it, privately through GitHub's private vulnerability reporting: the
**Report a vulnerability** button on this repository's Security tab. Do not open
a public issue.

Include the section and rule involved, the funds at risk and a reproduction.
We acknowledge reports within three working days and agree a disclosure date
with you. A fix to the specification that changes scripts, signature domains or
safety rules is published together with the disclosure, so that funded swaps
can still be recovered.
